# 3D Design Foundations

Course materials for **3D Design Foundations** — Smart Interactive Media, 1st semester, TH Rosenheim.

Published site: https://cyberhirsch.github.io/3DDesignFoundations/

## Contents

- `index.html` — course hub: software and assets, schedule, and links to everything below
- `checklists.html` — the homework checklist: each week's steps and what to hand in, as tick lists (14 weeks, 88 items; the ones marked Hand in are uploaded)
- `shortcuts.html` — 77 Blender shortcuts and menu paths (basics, subdivision modeling, sculpting,
  UVs, Shader Editor), each with a screenshot of what it does on hover, and five modifiers:
  Solidify, Lattice, Screw, Curve Bevel and Mirror
- `topology.html` — SubD topology cheat sheet: rules, support loops, levels, poles, n-gons, holes,
  caps, loop reductions and inside corners, each as a cage, its subdivided result and a reflection
  check (47 renders), a pattern library of 42 solved problems (24 checked diagrams, 18 tile renders)
  with a printable poster (`img/topology/topology_poster.png` and `.pdf`), plus a hand-in check and a
  fix table. Generated by `_topology/build_page.py` (renders by `_topology/build_renders.py` in
  Blender 5.2, poster by `_topology/build_poster.py`); edit the scripts, not the page
- `capture.html` — Weeks 4 and 8 capture card for the phone, object or place mode, with a tick list
  saved in the browser (`3ddf-capture-v1`). Generated by `_capture/build_page.py`
- `colour.html` — Week 5 interactive tool: linear vs sRGB slider, a colour-or-data sorting game
  (best score in `3ddf-colour-v1`) and the colour-space settings in Blender, Painter and Unreal.
  Hand-written, one file
- `axes.html` — Weeks 1 and 10 interactive tool: axes, hand and units of nine programs and formats, a
  converter with the fixing settings, pivot/origin and a quiz (`3ddf-axes-v1`). Hand-written, one file
- `pipeline.html` — Weeks 5, 6, 10, 11 cheat sheet: Blender → Painter → Unreal hand-offs, maps and
  colour spaces, normals, scale and axes, hand-in check and fixes. Generated by `_pipeline/build_page.py`
- `lens.html` — Week 9 interactive tool: field of view and depth of field on a live camera, dolly vs
  zoom, top view and a guess-the-lens quiz (`3ddf-lens-v1`). Hand-written, one file
- `light.html` — Weeks 11 and 12 interactive reference: colour temperature, inverse square law, lux
  and EV100, three-point lighting and fixes (`3ddf-light-v1`). Hand-written, one file
- `slides/` — the slides from class, exported from Dek without speaker notes (Weeks 1 to 6 so far). Images
  licensed for teaching only are replaced with a note that they were shown in class.
- `files/` — exercise files for class: `hirsch_teapot_materials_v001.blend` (Week 6, Blender 5.2)
- `img/` — the screenshots, taken in Blender 5.2 with factory settings at 2× UI scale and shown at
  half size

Slide decks are added per week as they are finished.

## Notes

The checklist items follow the course's homework document; when one changes, change the
other, and the count above.

The checklists keep their state in the browser's local storage, so progress survives a
reload but lives only on the device it was entered on. Nothing is submitted or shared from
these pages.
