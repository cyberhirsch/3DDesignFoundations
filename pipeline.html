Asset pipeline

From Blender 5.2 through Substance 3D Painter into Unreal Engine 5.8: what leaves each program, in which format, with which settings, and what to check when it arrives. For Weeks 5, 6, 10 and 11.

The route

Your asset travels on two roads. The mesh goes from Blender straight to Unreal. Its textures take the detour through Painter, which bakes the high-poly onto the low-poly and paints the layers. The two meet again in Unreal, in a material instance.

Blender 5.2Weeks 2–5

Model, sculpt, retopologize, unwrap.

1→FBX low + high
PainterWeek 6

Bake, layers and masks, export.

2→3 PNG textures
Unreal 5.8Weeks 10–11

Assemble, material, light.

3The mesh skips Painter: Blender → Unreal as USD, the whole scene at once (Week 10).

Week 6’s rule for every hand-off: author freely, export explicitly, validate somewhere else. Open each export in a second program before you trust it.

Hand-off 1 · Blender → Painter

1The mesh pair, for baking

Exported in Week 5 · baked in Week 6

ExportThe low-poly with its UVs, and the high-poly it bakes from, as two files: familyname_asset_low_v001.fbx and familyname_asset_high_v001.fbx.
Before
  • Scale applied: Sidebar (N) → Item shows Scale 1, 1, 1. If not, save a new version, then Ctrl+A → Scale.
  • Low and high sit in exactly the same place. Never move one of them.
  • Every part named in pairs, seat_low and seat_high. Name the mesh data like the object.
  • UVs on the low-poly: no overlaps, no flipped islands, a UV seam on every hard edge.
  • If you triangulate, add a Triangulate modifier as the last modifier of the low-poly now, and keep it. See Bake = engine.
BlenderFile → Export → FBX (.fbx): Limit to Selected Objects, Object Types Mesh, Apply Modifiers on. Leave the rest at its defaults: Forward −Z, Up Y, Apply Scalings All Local, Apply Unit on, Smoothing Normals Only.
PainterFile → New: File = the low-poly FBX, Resolution 2048. Under Advanced: Normal Map Format DirectX, Compute Tangent Space per Fragment on (Adobe: Unreal needs it).
BakeBaking mode (F8). High Definition Meshes: the high-poly FBX. Match By Mesh Name, suffixes _low and _high. Cage: distance based, Max Frontal and Max Rear Distance. Bake all seven maps.
CheckRead the log. Red zones mean the cage cuts into the model. Look at every map: no holes, no foreign shapes, no dark seams.

Hand-off 2 · Painter → Unreal

2The texture set

Exported in Week 6 · imported in Week 11

PainterFile → Export Textures, Export settings tab: Output template Unreal Engine (Packed), File type PNG 8 bit, Size based on each Texture Set’s size, Padding Dilation infinite.
Out comeThree files per Texture Set: …_BaseColor (colour), …_Normal (DirectX) and …_OcclusionRoughnessMetallic (AO in red, roughness in green, metallic in blue).
StoreIn a folder familyname_asset_textures_v001, the files named Unreal’s way: T_Chair_BaseColor.png, T_Chair_Normal.png, T_Chair_OcclusionRoughnessMetallic.png.
UnrealDrag the PNGs into a Content Browser folder. Double-click each texture and set sRGB and Compression Settings as in the map table. Then one parent material M_ with a Texture Sample per map, Sampler Type to match, converted to parameters, and one instance MI_ per object.
CheckOpen the three PNGs in a second program first. Then in Unreal, the Detail Lighting view: the normal detail should look raised, not dented.

Hand-off 3 · Blender → Unreal

3The scene, as USD

Week 10 · one late object can come as FBX

Before
  • Procedural materials baked to image textures: node trees don’t travel.
  • Pivot at the base, where the object touches the floor: Object → Set Origin (Blender calls the pivot the origin).
  • Scale applied, and Scene Properties → Units: Unit Scale left at 1.0.
  • The low-poly with the same modifiers it had for the bake.
BlenderFile → Export → Universal Scene Description: familyname_scene_layout_v001.usdc. General: Units Meters. Object Types: World Dome Light off. Keep UV Maps, Normals and Materials on (the defaults).
UnrealA Blank project with the USD Importer plugin on. File → Import Into Level, pick the .usdc: this is the route for the scene you hand in. The USD Stage keeps a live link instead, for trying changes.
One objectFBX with the settings of hand-off 1, from an object at the world origin: otherwise its distance from the origin ends up inside the mesh and the pivot lands beside it. In Unreal’s import options, leave Convert Scene and Convert Scene Unit on.
CheckMeasure one object you know: drag with the middle mouse button in the viewport, in centimetres. Our chair: 95 cm. A size that’s wrong gets fixed in Blender and exported again, never scaled in Unreal.

  1. Only base colour is a colour. Every other map is data: sRGB off in Unreal, Non-Color in Blender.
  2. In Unreal: double-click the texture → Details → Texture → sRGB, and Compression → Compression Settings.
  3. In the material, the ORM sample feeds three inputs: R → Ambient Occlusion, G → Roughness, B → Metallic.
  4. A Texture Sample’s Sampler Type must match its texture, or the material won’t compile.
  5. Unreal spots most normal maps by their pixels and sets them itself. It imported our ORM with sRGB on. Check every texture after import.

Normal maps: OpenGL or DirectX

A tangent-space normal map stores a direction in red, green and blue. Programs disagree about one thing: which way green points. Read with the wrong convention, every bump turns into a dent.

ProgramExpectsWhere to set or flip
Blender 5.2OpenGLImage Texture on Non-Color → Normal Map node, Tangent Space. Its own bakes are OpenGL (Normal Space Tangent; swizzle +X, +Y, +Z). There is no DirectX switch: for a DirectX map, invert green with Separate Color, Math (1 − G) and Combine Color.
Painteryour choiceFile → New → Normal Map Format. The export converts: Unreal Engine (Packed) writes DirectX, whatever the project uses.
Unreal 5.8DirectXFor an OpenGL map: double-click the texture → Texture, open the advanced options → Flip Green Channel.

The test: light a bump from above. If it looks raised, the convention is right. If the light seems to come from below, green is flipped.

  1. Leave the axis settings at their defaults on both ends. An object lying on its back means a setting was changed; fix the setting, don’t rotate the object by hand.
  2. Blender’s +Y is Unreal’s −Y, and turns about Z change sign: −14° in Blender reads +14° in Unreal. The importer handles it; only numbers you type across by hand go wrong.
  3. Apply scale in Blender before the bake and before every export, so bevels, bakes and sizes agree.
  4. After every import, measure one object you know.

The bake and the engine must agree

A normal map is made for one set of mesh normals and one set of triangles. Change either after the bake, and seams and wavy shading appear in Unreal that weren’t there in Painter.

  1. Same normals. Set the smoothing before the bake (Shade Smooth or Shade Auto Smooth, weighted normals if you use them) and don’t touch it after.
  2. Hard edge, UV seam. Every hard edge gets a UV seam, or the bake draws a dark line along it.
  3. Same triangles. Painter and Unreal both cut your quads into triangles, and not always the same way. A Triangulate modifier, last on the low-poly’s stack before the Week 5 export, fixes the triangles for good; the USD export applies it again in Week 10.
  4. Same tangents. Blender, Painter and Unreal all use MikkTSpace. In Unreal’s FBX import options (Common Meshes, Build), keep Use Mikk TSpace on.
  5. Keep your normals. Recompute Normals is on by default in those options: Unreal then ignores the normals in the file and calculates its own. If you set custom or weighted normals, switch it off.
  6. One file, both ways. Bake from the same low-poly you send to Unreal. Edit the mesh after the bake, and you bake again.
